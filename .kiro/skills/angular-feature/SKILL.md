description: Implementa o revisa una feature Angular standalone con rutas lazy, Signals, formularios, HTTP y pruebas.
---

1. Sigue una spec aprobada y conserva módulos por feature.
2. Implementa ruta lazy, contenedor y componentes presentacionales standalone OnPush.
3. Modela estado con Signals; usa RxJS para HTTP, debounce, switchMap y cancelación.
4. Usa Reactive Forms tipados y `FormBuilder.nonNullable`; valida y comunica errores accesiblemente.
5. No uses `any`; añade Vitest para servicios y UI; ejecuta lint, test y build.
