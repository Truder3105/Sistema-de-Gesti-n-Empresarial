# Tecnología

- Usa Java 25, Spring Boot 4.1.x, Maven y PostgreSQL en backend; Angular 22 y TypeScript estricto en frontend.
- Verifica versiones y compatibilidad en documentación oficial antes de actualizarlas.
- Usa DTOs `record`, constructor injection, validación Jakarta, Flyway y OpenAPI.
- En Angular, usa componentes standalone, Signals, rutas lazy y RxJS para composición asíncrona.
- No agregues dependencias sin justificar su necesidad en la spec activa.
